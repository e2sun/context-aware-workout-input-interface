# context-aware-workout-input-interface

Phone-sized React prototype for entering structured workouts with context-aware
suggestion chips. See [docs/project-description.md](docs/project-description.md)
for the project goal and [docs/grammar.md](docs/grammar.md) for the workout grammar.

## Run locally

```sh
npm install
npm run dev     # open the printed http://localhost:5173 URL
npm test        # grammar/state tests
```

For the phone view in a desktop browser, use DevTools device mode (e.g. iPhone 14).
